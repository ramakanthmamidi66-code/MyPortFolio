# Personal Portfolio - DevOps Mini Project

## Project Description
This project is a personal portfolio website developed using HTML.

## Technologies Used
- HTML
- GitHub
- GitHub Actions
- GitHub Pages

## Features
- About Me
- Education
- Skills
- Projects
- Certifications
- Contact Information

## DevOps Workflow
HTML Code
→ GitHub Repository
→ GitHub Actions
→ Build
→ Deployment
→ GitHub Pages

## Deployment
The portfolio is deployed using GitHub Pages.

## Conclusion
This project demonstrates the basic DevOps process of version control,
continuous integration and continuous deployment.
